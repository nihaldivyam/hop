From the terminal

From the voyager repo

make short URL=https://kubernetes.io/docs/ SLUG=k8s
make short URL=https://example.com/very/long/path
make paste FILE=notes.md

Each prints the URL to share. The token is read over ssh from the box.

The hop CLI

export HOP_API=https://{{.LinksHost}}
hop login                       # stores the token locally
hop link https://example.com/docs k8s
cat error.log | hop paste
HOP_TTL=1d hop paste secrets.txt

The same binary is the client (go build in the repo).

Plain curl

curl -sS -H "Authorization: Bearer $HOP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://kubernetes.io/docs/","slug":"k8s"}' \
  https://{{.LinksHost}}/api/links

curl -sS -H "Authorization: Bearer $HOP_TOKEN" \
  -H "X-Title: notes.md" -H "X-TTL: 7d" \
  --data-binary @notes.md https://{{.PasteHost}}/api/pastes

Where is my token? On the box: /opt/voyager/secrets/hop.env (make hop-token in the voyager repo prints it). Reading a link or a paste never needs it.
